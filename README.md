# Parking_App · лабораторная работа №7

Парковочные места синхронизируются между окнами без перезагрузки страницы. В панели «События парковки» можно выбрать этаж и видеть уведомления об изменениях мест и входе или выходе других участников. Ветка для сдачи — `27`, основа — `lab26`.

## Запуск

Нужны Node.js 22.12+ (или 24 LTS), npm и MongoDB. Для демонстрации можно запустить MongoDB через существующий Docker Compose.

```bash
docker compose up -d mongodb
npm ci
cp .env.example .env
```

Укажите в `.env` собственный `JWT_SECRET` и строку подключения. Для локального контейнера из `docker-compose.yaml`:

```dotenv
MONGO_URI=mongodb://admin:secretpassword@127.0.0.1:27017/parking_lab7?authSource=admin
```

`PORT` по умолчанию равен 3000. `CORS_ORIGIN` задаёт допустимые адреса клиента. Если MongoDB работает отдельно, подставьте её URI и пропустите запуск контейнера.

```bash
# Только для отдельной демонстрационной БД: seed очищает пользователей и места.
npm run seed
npm start
```

В другом терминале запустите React:

```bash
cd client
npm ci
npm run dev -- --strictPort
```

Откройте [http://localhost:5173](http://localhost:5173). При другом адресе бэкенда задайте `VITE_API_URL` через `client/.env`. Для проверки сборки выполните `npm run build` в клиенте.

## Демонстрация в двух окнах

Используйте обычное и приватное окно или разные профили браузера: авторизация хранится в localStorage. Для первого входа используйте `user@parking.local` / `User123!`, для второго — `admin@parking.local` / `Admin123!`. Это демонстрационные учётные записи из seed.

| Действие | Ожидаемый результат |
|---|---|
| A и B выбирают этаж 1 в панели «События парковки» | В обоих окнах два подключения. В A появляется уведомление о входе B. |
| A занимает свободное место этажа 1 | B видит событие «Место … занято» и обновлённые карточку и статистику без F5. |
| B выбирает этаж 2, A освобождает место этажа 1 | A получает уведомление об уходе B и событие освобождения. В B обновляется список, а журнал этажа 2 не получает событие этажа 1. |
| B возвращается на этаж 1 и выходит из аккаунта | A видит уведомление об отключении и одно оставшееся подключение. |
| Сервер перезапускают при открытом A | После восстановления соединения клиент повторяет подписку и запрашивает текущее состояние парковки. |

Для отчёта снимите оба окна после бронирования на одном этаже и после переключения B на этаж 2 и освобождения места. Для проверки транспорта откройте DevTools → Network → WS и найдите соединение с `transport=websocket`.

## События Socket.IO

| Событие | Направление | Назначение |
|---|---|---|
| `floor:subscribe` | клиент → сервер | Проверка номера этажа, выход из предыдущей комнаты, вход в `floor:N`; ответ с количеством подключений. |
| `floor:presence` | сервер → комната | Подключение, отключение или смена этажа. Счётчик учитывает открытые соединения. |
| `floor:activity` | сервер → комната | Действие, номер места, этаж, время. При переносе действие получают комнаты обоих этажей. |
| `spaces:changed` | сервер → все клиенты | Сигнал повторно запросить список и статистику по REST. |
| `session:expired` | сервер → клиент | Завершение соединения после истечения JWT. |

CRUD и бронирования выполняются существующим REST API с проверкой ролей, а Socket.IO отправляет события после успешной записи в MongoDB. При освобождении существующая история парковки пополняется записью о сессии. Панель событий показывает до пяти полученных уведомлений выбранного этажа за текущий сеанс просмотра.

## Основные маршруты API

| Метод и путь | Доступ |
|---|---|
| `POST /auth/register`, `POST /auth/login` | Открытый |
| `GET /spaces`, `GET /spaces/stats`, `GET /spaces/:id` | Открытый |
| `GET /profile`, `POST /spaces/:id/occupy`, `POST /spaces/:id/release` | JWT. Освобождение доступно владельцу места и администратору. |
| `POST /spaces`, `PUT /spaces/:id`, `DELETE /spaces/:id`, изменение тегов | Администратор |

```bash
git fetch origin lab26

git push -u origin lab27
```

Ветка публикуется аккаунтом с правом записи в Parking_App. Для локального запуска из ZIP можно открыть папку `Parking_App-27` и выполнить команды из раздела «Запуск».
